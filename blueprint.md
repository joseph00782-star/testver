
# Lotto Number Generator

## Overview

A simple, visually appealing web application to generate random lottery numbers.

## Project Outline

*   **index.html**: Main HTML file.
*   **style.css**: CSS for styling.
*   **main.js**: JavaScript for lottery number generation and UI interaction.
*   **lotto-display (Web Component)**: A custom element to display the generated lottery numbers.

## Design and Features

*   **Modern UI**: Clean and modern design with a focus on user experience.
*   **Responsive**: Works on both mobile and web.
*   **Interactive**: A button to generate new lottery numbers.
*   **Visuals**: Use of colors, fonts, and animations to make the experience engaging.
